# Ron's Wedding 💍

A beautiful, modern wedding website built with Next.js, React, and TypeScript. Features an elegant hero section, countdown timer, event details, gallery, RSVP form, and interactive animations.

## ✨ Features

- **Responsive Design**: Fully responsive and mobile-friendly interface
- **Countdown Timer**: Live countdown to the wedding day
- **Event Information**: Detailed section for wedding events and schedule
- **Photo Gallery**: Beautiful carousel gallery for wedding photos
- **RSVP System**: Interactive form for guests to RSVP
- **Location Details**: Venue information and map integration
- **Music Toggle**: Background music controls
- **Interactive Animations**: Smooth animations using GSAP and custom effects
- **Theme Provider**: Built-in theme customization support

## 🛠️ Tech Stack

| Technology | Purpose | Why Used |
|-----------|---------|----------|
| **[Next.js](https://nextjs.org/)** | React Framework | Server-side rendering, optimized performance, and built-in SEO support for a professional wedding site |
| **[TypeScript](https://www.typescriptlang.org/)** | Programming Language | Type safety, better IDE support, and fewer runtime errors for maintainable code |
| **[Tailwind CSS](https://tailwindcss.com/)** | Styling Framework | Rapid UI development, consistent design system, and responsive utilities out of the box |
| **[PostCSS](https://postcss.org/)** | CSS Processing | Plugin ecosystem for advanced CSS features and optimization |
| **[shadcn/ui](https://ui.shadcn.com/)** | Component Library | Pre-built, customizable UI components following accessibility standards |
| **[GSAP](https://greensock.com/gsap/)** | Animation Library | Smooth, performant animations for interactive effects and transitions |
| **[pnpm](https://pnpm.io/)** | Package Manager | Faster installations, better disk space efficiency, and strict dependency management |


## 📁 Project Structure

- **`app/`** - Next.js app directory with main layout and pages
- **`components/`** - Reusable React components
  - **`ui/`** - UI component library (button, card, form, etc.)
  - **`wedding/`** - Wedding-specific components (countdown, gallery, RSVP, etc.)
- **`config/`** - Configuration files (wedding details)
- **`hooks/`** - Custom React hooks
- **`lib/`** - Utility functions and helper libraries
- **`public/`** - Static assets (images, videos, audio)
- **`styles/`** - Global stylesheets
